# My Task List

**Name:** Aya Grefi

## Description
My Task List is a simple interactive web application that allows users to create and manage tasks. Users can enter a task name, choose a priority level, add the task to the page, mark tasks as completed, and delete tasks.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the form to enter a task and select a priority.
5. Click **Add Task** to add the task to the list.
6. Use the **Complete** button to mark a task as completed.
7. Use the **Delete** button to remove a task.

## Features
- Add tasks
- Select Low, Medium, or High priority
- Mark tasks as completed
- Delete tasks
- Prevent empty tasks from being added

There are currently no known problems or incomplete features.
